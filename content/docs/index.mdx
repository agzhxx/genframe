Genframe is a set of React components for AI image and video tools. It isn't an npm package:
like shadcn/ui, each item is copied into your project, where you can read and change it.

## Requirements

- React 19 and Tailwind CSS v4.
- A project with shadcn set up (`npx shadcn@latest init`). Items are written for shadcn's Radix
  and Base UI styles (`radix-*` and `base-*` in `components.json`); the React Aria styles
  (`aria-*`) aren't supported yet.

## Add the registry

Map the `@genframe` namespace once per project:

```bash
npx shadcn@latest registry add @genframe=https://agzhxx.github.io/genframe/r/{name}.json
```

## Install an item

```bash
npx shadcn@latest add @genframe/compare-slider
```

The slider lands in `components/ui/compare-slider/` (wherever your `ui` alias points) and brings
the Genframe items it needs with it: `use-reduced-motion` and `motion-tokens`.

Items also install by URL:

```bash
npx shadcn@latest add https://agzhxx.github.io/genframe/r/use-reduced-motion.json
```

Without the namespace, that works only for items with no Genframe dependencies, like
`use-reduced-motion`, `estimate-cost`, `generation-queue-reducer`, `use-thumbhash`, `video-pool`,
`masonry-layout`, `timecode` and `motion-tokens`. The components need the namespace mapped first,
since shadcn finds their Genframe dependencies through it.

Each item brings the items it needs with it.

## Sizes

Each item's page shows its size: the item's own code plus the npm packages it brings, minified
and gzipped, the way your app's bundler would ship it. React and the shadcn parts it builds on
aren't counted, since your app has them already; neither are other Genframe items, which have
sizes of their own. Every item has a budget, and CI fails when one grows past it.
